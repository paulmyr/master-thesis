# Master Thesis Repository
--------------------------

This Repository is structured as follows:
1) `1_orga` contains project planning and other formal stuff
2) `2_thesis` contains the actual written report and everything directly related to the produced pdf
3) `3_jaxey` contains the code for the neuron simulator used for this Thesis
4) `4_data` contains data from stimulated striatal projection neurons that are used as baseline data
5) `5_code` contains any additional code written (that is not directly added to the neuron simulator), e.g. evluation files.

## Setup
--------

To get started with the following steps:
1) clone this repository
2) `run ./setup` to install dependencies etc.
3) `source .venv/bin/activate` to use virtual environment
4) `cd 5_evaluation` and `python <filename>.py` to run file
5) notebooks in `5_evaluation/notebooks/` can be run in google colab.
