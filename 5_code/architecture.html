5. Guarino Loss: Differentiable Feature Pipeline

jx.integrate(cell, params=params) │ ┌─────────┴─────────┐ ▼ ▼ voltage[T] spikes[T] (soft, from AdExSurrogate) │ │ │ GuarinoFeatureExtractor.extract() │ ┌───────────────┴──────────────────────────────┐ │ │ │ │ ▼ ▼ │ soft_spike_count(spikes) soft_time_to_nth_spike() │ │ soft_time_to_last_spike() │ ▼ soft_inverse_first_isi() │ n_spikes ──► has_first/second/ soft_inverse_last_isi() │ third_spike soft_firing_frequency() │ (sigmoid gating) │ │ │ ▼ ▼ v_stim_end t_first, t_second, t_third (voltage[idx]) t_last, inv_isi_first/last │ firing_freq └──────────────┬─────────────────────────────────┘ ▼ GuarinoFeatures (simulated, differentiable) │ ┌──────────────┴──────────────┐ ▼ ▼ GuarinoFeatures (sim) GuarinoFeatures (exp) (hard spike detection, non-differentiable) │ ▼ guarino_loss() for each feature: error = |sim - exp| / |exp| loss += weight × validity × error + penalty │ ▼ scalar loss ──► jax.value_and_grad() │ ▼ parameter updates

6. Key Design Decisions

  • ExperimentConfig is the single source of truth for all hyperparameters — presets are named deep-copies of it.
  • TraceData vs SimulationResult: TraceData holds raw experimental recordings (with stimulation window metadata); SimulationResult holds Jaxley/Brian2 output (voltage + adaptation current w + spike trace).
  • Loss functions are closures: make_guarino_loss_fn(), make_mse_loss_fn(), and make_soft_dtw_loss_fn() capture the cell, data stimuli, and target data, returning a params → scalar function compatible with jax.value_and_grad().
  • ExperimentRunner is the orchestrator that wires the full lifecycle: load data → train → evaluate → plot → save.
  • Evaluator owns both metric computation (coincidence factor Γ, timing errors) and all matplotlib visualization.
  • TrainingResult stores params in Jaxley’s internal format ([{"AdEx_g_L": Array}]); get_params_dict() converts to {"g_L": float}.
  • Soft feature extraction uses temperature-scaled power sharpening and sigmoid-gated cumulative sum masks to make discrete spike operations differentiable.
  • Parameter clipping is applied after each gradient step using biophysically realistic bounds from PARAM_BOUNDS.
