Architecture overview for the ADoptEX package — differentiable AdEx neuron parameter optimization

1. Module Responsibilities

6. Installation & Usage

Install (editable mode)

pip install -e 5_code/

Notebook usage

# Import building blocks from ADoptEX.core.data import load_trace from ADoptEX.core.parameters import DEFAULT_PARAMS, PARAM_BOUNDS from ADoptEX.core.simulation import simulate_with_current_trace from ADoptEX.loss import make_guarino_loss_fn, make_mse_loss_fn, make_soft_dtw_loss_fn from ADoptEX.training import train, setup_trainable_cell, TrainingConfig from ADoptEX.evaluation import coincidence_factor from ADoptEX.config import ExperimentConfig # Load experimental data trace = load_trace("voltage_ch5.dat", "current_ch4.dat") # Set up cell & optimizer cell, data_stimuli, t_max, params = setup_trainable_cell( DEFAULT_PARAMS, trace.current, trace.dt_ms ) loss_fn = make_guarino_loss_fn(cell, data_stimuli, t_max, trace, ...) # Train config = TrainingConfig(optimizer="adam", learning_rate=0.1, n_epochs=500) result = train(loss_fn, params, config) print(result.get_params_dict()) # Evaluate sim = simulate_with_current_trace(result.get_params_dict(), trace.current, trace.dt_ms) gamma = coincidence_factor(trace.spike_times, sim.spike_times, trace.duration_ms) print(f"Γ = {gamma.gamma:.3f}")

7. Key Design Decisions

  • Notebook-first workflow: the library exposes importable building blocks (loss functions, training loop, data loading, evaluation). Orchestration, plotting, and experiment presets belong in notebooks.
  • ExperimentConfig is the single source of truth for all hyperparameters.
  • TraceData vs SimulationResult: TraceData holds raw experimental recordings (with stimulation window metadata); SimulationResult holds Jaxley/Brian2 output (voltage + adaptation current w + spike trace).
  • Loss functions are closures: make_guarino_loss_fn(), make_mse_loss_fn(), make_soft_dtw_loss_fn(), and make_deistler_loss_fn() capture the cell, data stimuli, and target data, returning a params → scalar function compatible with jax.value_and_grad().
  • TrainingResult stores params in Jaxley’s internal format ([{"AdEx_g_L": Array}]); get_params_dict() converts to {"g_L": float}.
  • Soft feature extraction uses temperature-scaled power sharpening and sigmoid-gated cumulative sum masks to make discrete spike operations differentiable.
  • Parameter clipping is applied after each gradient step using biophysically realistic bounds from PARAM_BOUNDS. Alternatively, sigmoid reparameterization (use_param_transform=True) maps parameters through a smooth bijection so the optimizer works in unconstrained space — gradients flow smoothly near boundaries.
